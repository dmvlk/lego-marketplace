# Фронтенд БрикМаркет

Клиентская часть на React, TypeScript и Vite. Доступны каталог с поиском и фильтрами, избранное, управление объявлениями, профиль, сделки и предложения, защищенная демо-оплата, доставка и осмотр, споры с доказательствами, отзывы продавцам и сообщения.

Доступные действия зависят от роли и статуса сделки. Пункт модерации споров отображается только пользователям с ролью `ADMIN`. Платежи работают в демо-режиме: реальные деньги не списываются и не переводятся.

## Запуск

Сначала запустите API и сервисы из корня проекта:

```powershell
docker compose up --build -d
```

Затем в каталоге `frontend` установите зависимости и запустите Vite:

```powershell
npm install
npm run dev
```

Откройте `http://localhost:5173`. Адрес API по умолчанию - `http://localhost:8000/api/v1`. Его можно изменить через переменную `VITE_API_URL` в локальном `.env`.

Для собственного адреса API скопируйте пример и измените значение:

```powershell
Copy-Item .env.example .env
```

## Проверки

```powershell
npm run lint
npm run build
```

Токены хранятся в `sessionStorage` текущей вкладки. При истечении access-токена клиент использует refresh-токен и сохраняет новую пару.
