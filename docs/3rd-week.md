# Третья неделя: интерфейс маркетплейса

## Суть этапа

Создан пользовательский фронтенд LEGO-маркетплейса и подключены основные сценарии покупателей, продавцов и администраторов через API Gateway. Интерфейс поддерживает поиск товаров, публикацию объявлений, общение и оформление сделок от предложения до отзыва.

## Стек

- React 19 и TypeScript
- Vite 8 для локального запуска и production-сборки
- CSS для адаптивной верстки
- FastAPI API Gateway для связи с backend-сервисами
- Docker Compose для запуска API и зависимостей

## Основные окна

- Каталог: поиск и фильтры, карточки объявлений, покупка, предложение цены и связь с продавцом
- Избранное: сохраненные объявления
- Мои объявления: создание, редактирование, архивирование и загрузка фотографий
- Сделки и предложения: покупки, продажи, встречные предложения, демо-оплата, доставка, осмотр, споры и отзывы
- Сообщения: список диалогов и переписка через REST API и WebSocket
- Модерация споров: запрос доказательств, просмотр аудита и запуск решения для пользователей с ролью `ADMIN`
- Профиль: изменение отображаемого имени и ссылки на аватар

## Запуск в PowerShell

Из корня репозитория запустить backend:

```powershell
docker compose up --build -d
```

Затем из каталога `frontend` установить зависимости и запустить Vite:

```powershell
Set-Location frontend
npm install
npm run dev
```

Открыть `http://localhost:5173`. Адрес API по умолчанию: `http://localhost:8000/api/v1`. Для изменения адреса используется `VITE_API_URL` в локальном `.env`.

Проверки фронтенда запускаются из каталога `frontend`:

```powershell
npm run lint
npm run build
```
