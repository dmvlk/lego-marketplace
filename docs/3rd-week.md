# Третья неделя: фронтенд пользовательских сценариев

## Результат этапа

Создан фронтенд маркетплейса на React, TypeScript и Vite. Пользовательские страницы связаны с API Gateway и поддерживают основные сценарии покупателей, продавцов и администраторов.

## Реализованные возможности

- регистрация, вход, выход, обновление сессии и редактирование профиля;
- каталог объявлений с поиском, фильтрами, сортировкой и избранным;
- создание, редактирование, архивирование объявлений и загрузка фотографий;
- создание предложений цены, встречные предложения, принятие и отклонение;
- офлайн-сделки и защищенные онлайн-сделки;
- демонстрационная оплата без списания реальных денег;
- создание отправления продавцом, обновление трек-номера и истории статусов;
- подтверждение доставки, инспекционный период и завершение сделки;
- открытие спора, текстовые и графические доказательства;
- панель администратора для запросов доказательств, аудита и решений по спорам;
- переписка через REST API с обновлением сообщений по WebSocket;
- отзывы о продавцах с отображением среднего рейтинга и комментариев.

## Проверки

- `npm run lint` завершился без замечаний;
- `npm run build` выполнил проверку TypeScript и production-сборку;
- целевые тесты сервиса сделок прошли: 5 тестов;
- целевые тесты сервиса авторизации прошли: 3 теста;
- Gateway отвечает на health-проверку, маршрут получения спора по сделке опубликован;
- в браузере проверены каталог, окно входа и отсутствие горизонтальной прокрутки на ширине 375 пикселей.

Полные браузерные сценарии сделок и переписки не прогонялись, так как в тестовом каталоге не было активного объявления и тестового аккаунта. Для платежей используется только демонстрационный режим.

## Итог

Фронтенд готов к пользовательской проверке. Для следующего этапа остается прогнать сквозные сценарии с тестовыми аккаунтами и объявлениями.
